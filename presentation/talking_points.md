# 5-minute expo flow
1. Problem: "Does this outfit work?" is subjective and fast to second-guess.
2. Live demo: Home -> *Try the demo outfit* (white shirt, blue pants, red shoes) -> score ~low -> Recommendations -> Apply white shoes -> score jumps.
3. Camera demo: Analyze Outfit -> Camera for each piece -> fix colour if needed.
4. Wardrobe: *Load sample wardrobe* -> Generate outfits -> best 5 of 125.
5. Model Performance: 3-model table, confusion matrix; state plainly that labels are rule-based and how feedback votes improve it.
6. Roles: one slide per member (see docs/TEAM_GUIDE.md).
